# 🧪 Scope Creep Detector — Real-World Test Cases

This directory contains 5 curated, real-world test case scenarios designed to evaluate scope creep detection, cost estimation, and change order generation in **Scope Creep Detector**.

Each scenario folder includes:
- `README.md` — Copy-paste form values for `/app/analysis/new`.
- `project-details.json` — Machine-readable form metadata.
- `01-*.txt` — Baseline scope agreement conversation.
- `02-*.txt` & `03-*.txt` — Client conversation threads containing scope creep, new feature asks, and out-of-scope demands.

---

## 📁 Test Case Directory

- **Scope Creep Evaluated**: Custom loyalty reward points engine, real-time NetSuite ERP inventory sync, multi-currency & multi-language checkout.
